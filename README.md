# Cursors

A version-controlled home for the *Cursors* novel by K. La Don Smith.

This repository will hold the manuscript, character profiles, worldbuilding, timelines, research, and selected reference images. Keep exploratory notes separate from canonical manuscript text.

## Proposed structure

- `manuscript/` — chapters and scenes
- `characters/` — character profiles
- `worldbuilding/` — locations, systems, concepts
- `timeline/` — chronology and continuity
- `research/` — supporting references
- `assets/` — optimized character art and diagrams
- `publication/` — edition and release notes

See [AGENTS.md](AGENTS.md) for editorial conventions.
